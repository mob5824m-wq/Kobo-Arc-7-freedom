Every full install method runs the same patches

Offline camera QR byte transfer

Files can transfer actual file bytes through repeated QR frames, with no shared network. Long-press a file in Files and choose Send file bytes via QR, then open Receive QR bytes on the other Kobo, or use this self-contained browser companion on a computer/phone. The native QR Transfer app has a file picker, three densities and resumable on-disk receiving. Up to 64 MiB (legacy: 1 MiB); optical transfers are slow, so use LAN sharing for speed. Codes are not encrypted.

Download offline QR byte-transfer companion

Save the HTML file and open it locally. Browser camera reception requires a secure context (HTTPS/localhost; local files work in some browsers). Displaying codes for the Kobo camera works offline.
